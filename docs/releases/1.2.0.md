# Release 1.2.0

Date: 2026-11-11. Previous release: 1.1.0.

A design release. No content, import or access rule changed.

## Changes

- **The header no longer changes when the page is scrolled.** Olivero pins its header
  and folds the menu into a button once the page scrolls. The Navigator theme now has
  its own page template without the marker Olivero's script looks for, so the header
  scrolls away with the page.
- **One header bar.** The tall blue box beside a lighter strip is now a single blue
  bar, about half the height, with the site name on the left and links on the right.
  Small screens keep a "Menu" button.
- **One left edge.** The header, page content and footer share one centred container.
  Before, each started at a different position.
- **Tighter spacing.** Olivero spaces the parts of every list 54px apart; the home
  page and journey pages now set their own spacing.
- **Home page in two columns** on wide screens. Journeys stack on smaller ones.
- **Footer with content.** It says the site is not a GNWT website, tells visitors to
  check the official page before acting, and links to the source code. It stays at
  the bottom of the window on short pages.
- **Journey pages** use the same compact list as the home page, and no longer show
  an RSS feed icon (the feed display was removed from the list's settings).

## Roll back

This release changes no data, so no database restore is needed:

```bash
git checkout v1.1.0
composer install --no-dev
vendor/bin/drush deploy
```
