# Release 1.3.0

Date: 2026-11-12. Previous release: 1.2.0.

Accessibility fixes, automated checks on GitHub, and a scheduled backup. No content,
import or access rule changed.

## Changes

- **Accessibility fixes** (details in [accessibility.md](../accessibility.md)):
  - The header is a darker blue, so its white text has a contrast of at least 5:1.
    It was 3.1–3.5:1 at the light end, below the 4.5:1 that small text needs.
  - Focus outlines on buttons, tabs and header links are now easy to see.
  - Messages and tabs sit inside the page's main area, which fixes the one problem
    the axe scanner reported (on the Log in page).
- **Automated checks on GitHub.** Every push runs the Composer checks, the automated
  tests, the Drupal coding standards check and `composer audit` on PHP 8.3
  (`.github/workflows/ci.yml`).
- **Composer is pinned to PHP 8.3,** the version the server runs. One test-only
  package (doctrine/instantiator) needed PHP 8.4 and moved from 2.1.0 to 2.0.0. The
  server installs without test tools, so it was never affected.
- **Scheduled backup.** `scripts/backup.sh` backs up the database every night and
  keeps 14 days. A backup was restored into a separate copy of the site as a test
  (details in [backup-and-restore.md](../backup-and-restore.md)).
- **Import test for a changed row,** recorded in the
  [demo data notes](../../migrations/demo-data/README.md).

## Fixed on the server (not part of the code)

Drupal's scheduled tasks had not run since 2026-11-11. The file that schedules them
(`/etc/cron.d/nsn-drupal`) was writable by its group, and cron refuses such files.
Its permissions were corrected on 2026-11-12 and cron accepted it. Lesson: after
adding a scheduled task, check the system log to confirm it was accepted.

## Roll back

This release changes no data, so no database restore is needed:

```bash
git checkout v1.2.0
composer install --no-dev
vendor/bin/drush deploy
```
