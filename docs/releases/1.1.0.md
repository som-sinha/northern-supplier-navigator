# Release 1.1.0

Date: 2026-11-10. Previous release: 1.0.0.

A security update to Drupal core and its add-ons, plus readable page addresses,
removal of default Drupal pages, and the first automated tests.

## Security update

`composer audit` reported **13 known security problems in 8 packages** before this
release (all in Symfony, the library Drupal is built on, and all published on or
after 2026-11-04). After the update it reports none.

| Package | Before | After | Problems fixed |
|---|---|---|---|
| Drupal core | 11.4.11 | 11.4.12 | brings in the Symfony fixes below |
| symfony/http-foundation | 7.4.21 | 7.4.23 | 4 |
| symfony/serializer | 7.4.21 | 7.4.23 | 3 |
| symfony/filesystem | 7.4.21 | 7.4.23 | 1 |
| symfony/http-kernel | 7.4.21 | 7.4.23 | 1 |
| symfony/mime | 7.4.19 | 7.4.22 | 1 |
| symfony/routing | 7.4.21 | 7.4.23 | 1 |
| symfony/validator | 7.4.21 | 7.4.23 | 1 |
| symfony/yaml | 7.4.21 | 7.4.23 | 1 |

Add-ons updated at the same time: Migrate Plus 6.0.10 → 6.0.11, Migrate Source CSV
3.8.0 → 3.10.0, Migrate Tools 6.1.4 → 6.1.5, Entity Reference Revisions 1.14.0 → 1.15.0.

No database updates were needed, and no settings changed as a result of the update.

## Other changes

- **Readable addresses.** Guides are now at `/guides/register-as-gnwt-bidder`
  instead of `/node/45`, and journeys at `/journeys/become-bidder`. Added the
  Pathauto add-on to create them.
- **Default Drupal pages removed.** `/node` showed a "Welcome to Drupal" page and
  `/rss.xml` an empty feed; both now return "not found". The unused Tags category
  and the "Powered by Drupal" footer are gone.
- **Independence notice.** Every page now says "Independent portfolio project. Not
  an official GNWT service." beside the site name.
- **Journey pages** list each guide as a title and summary instead of the full guide.
- **Automated tests.** Five tests for the `CsvChildren` import step and one that
  checks list filters against the review workflow (see
  [defect 001](../defects/001-moderated-content-filter.md)).
- **Smoke test.** `scripts/smoke-test.sh` runs 14 checks after a release.
- **Dashboard table** no longer uses a sticky header, and shortens source links.

## Roll back

A database snapshot named `before-11-4-12` was taken before the update.

```bash
git checkout v1.0.0
ddev composer install
ddev snapshot restore before-11-4-12
ddev drush cache:rebuild
```

Addresses under `/guides/` and `/journeys/` stop working after a rollback, because
1.0.0 does not have them.
