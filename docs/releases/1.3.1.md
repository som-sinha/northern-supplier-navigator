# Release 1.3.1

Date: 2026-11-12. Previous release: 1.3.0.

A small tidy-up of navigation. No content, import or access rule changed.

## Changes

- **Breadcrumb removed.** The site has no deeper levels, so the breadcrumb only ever
  said "Home", directly under a header that already has a Home link.
- **Log in page without tabs.** Drupal's "Log in / Reset your password" tabs are
  hidden on the log in, reset password and register pages. The Log in form has a
  "Forgot your password?" link instead, and the reset form a "Back to log in" link.
  Editors still see their tabs (View, Edit, Revisions) on guides.

## Files

- `web/themes/custom/nsn_theme/nsn_theme.theme` (two form changes)
- `web/themes/custom/nsn_theme/css/navigator.css`
- `config/sync/block.block.nsn_theme_*` (breadcrumb block removed; tab blocks hidden
  on the account pages)

## Roll back

This release changes no data, so no database restore is needed:

```bash
git checkout v1.3.0
composer install --no-dev
vendor/bin/drush deploy
```
